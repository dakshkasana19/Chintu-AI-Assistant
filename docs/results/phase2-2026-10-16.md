# Phase 2 Results — 2026-10-16

## Implemented

- Added `WakeWordDetector` interface and a local Vosk + faster-whisper implementation.
- VAD-delimited segments are the only audio passed to the detector. Vosk uses the restricted grammar `["chintu", "hey chintu", "ok chintu", "[unk]"]`.
- Vosk candidates are confirmed by faster-whisper base using the trailing `wake_confirm_window_seconds` audio (default 2 seconds), English transcription, and RapidFuzz matching against configured phrases and phonetic variants.
- Added validated `wake_sensitivity` (0.0–1.0; higher is more permissive) and `wake_cooldown_seconds` configuration.
- Confirmation runs on a bounded worker queue, separate from microphone frame capture. A confirmed wake transitions the runtime from sleeping through `WAKE_CONFIRM` to `LISTENING`.
- The microphone and wake detector run while the runtime is asleep; the UI overlay remains hidden until the detector confirms a wake phrase.
- Added a checksum-pinned downloader for `vosk-model-small-en-in-0.4`, safe ZIP extraction, faster-whisper base cache preparation, launcher setup, doctor status, and `scripts/eval_wake.py`.
- The evaluator accepts labeled 16 kHz PCM16 WAVs and reports positive miss rate plus negative false accepts per audio hour.

## Limitations

This phase recognizes the wake phrase only. Follow-up command transcription, command routing, PC actions, retrieval, answer generation, and TTS are not implemented. The detector's end-to-end wake accuracy has not yet been established on recorded speech.
